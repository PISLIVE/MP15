Database Dictionary

1. auth.users

The core authentication table managed by Supabase. Holds cryptographic identities and sessions.

2. public.user_settings

An extension table holding user application preferences. Has a strict 1-to-1 relationship with auth.users where user_id acts as both Primary and Foreign Key.

3. public.scan_history

The central transaction table of the application. Uses PostgreSQL's jsonb column type heavily. This is crucial for a footprint analyzer because APIs return highly dynamic data structures that would be inefficient to normalize into strict rows and columns.

4. public.shared_reports

Allows users to securely share reports. The scan_data column holds a duplicate JSON snapshot of a scan so that if the live data changes, the shared report remains exactly as it was when generated. expires_at provides TTL (Time-To-Live) access control.

5. public.monitored_emails

Drives the background cron jobs. The background worker iterates through this table, checks APIs, and updates last_checked. If new breaches appear that aren't in the known_breaches JSON array, it triggers an email alert.
